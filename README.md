# Month Class Demonstration
This was a simple project done for school in the past.

Features one class called Month that lets you iterate accross the 12 months in a simple way.
Allows accessing month names via an int, or month order via a string.

While this was achieved with a static array of strings for the sake of the class, a map would be a good alternative.
